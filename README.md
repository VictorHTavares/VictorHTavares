### Sobre

Desenvolvedor na **Modernização Pública e Informática**, onde trabalho na modernização de sistemas de gestão pública: telas web novas sobre bancos de dados legados, regras de negócio de licitações e contratos, e integrações com plataformas externas por API.

### No dia a dia

- **Backend** com NestJS e TypeORM sobre SQL Server: APIs REST, consultas e views em bancos legados, scripts de migração idempotentes
- **Frontend** com Next.js, React e TailwindCSS: listagens, formulários e telas de conferência para usuários finais
- **Integrações** com APIs de terceiros: envio de processos, sincronização de resultados e tratamento de erros e regras da plataforma externa
- **Banco de dados**: modelagem de tabelas e views, scripts SQL para implantação em clientes
